# Brand Blueprint

A responsive, dependency-free brand strategy workspace. The application includes foundation progress, interactive brand-building cards, a practical toolkit, responsive navigation, and a brand-guideline preview.

## Local development

```bash
npm run dev
```

Open [http://localhost:4173](http://localhost:4173).

## Production build

```bash
npm run lint
npm run build
npm run preview
```

The production output is written to `dist/`. The project intentionally has no runtime or package dependencies; Node.js and TypeScript are the only required tools.
